# Number Line

画面にランダムに並んだ数字を、1 から順番に線でつないでいくウェブゲームです。

## 遊び方

1. `index.html` をブラウザで開きます（ビルドや依存パッケージは不要です）。
2. 最初は `1` と `2` が表示されます。`1` を押したまま `2` までなぞると線がつながります。
3. 線は小さい数字から大きい数字の方向にしか引けません（`2` から `1` へは引けません）。
4. 全部つなぐとクリア。次のステージでは数字が 1 つ増え、`1〜3`、`1〜4` … と際限なく続きます。

- 一筆書きでまとめてつないでも、1 本ずつ指を離しながらつないでも構いません。
- つないだ線は指を離しても残ります。続きは最後につないだ数字（点滅している円）から引きます。
- 進んだステージはブラウザに保存されます。「最初から」でステージ 1 に戻れます。
- マウスとタッチ操作の両方に対応しています。

## ファイル構成

- `index.html` — 画面の骨組み
- `style.css` — 見た目（ライト / ダークモード対応）
- `game.js` — 配置・入力・描画などのゲームロジック
